# Is Linear/Nonlinear Information in LLMs Similar to Conscious/Unconscious Information in Humans?

An empirical investigation of whether LLMs' ability to introspect on their own internal states correlates with the linearity of those states' representations—testing the analogy between linear/nonlinear information encoding and conscious/unconscious information access.

## Key Findings

- **Linear features are perfectly introspectable**: GPT-4.1 achieves 100% self-report accuracy on sentiment classification and binary refusal prediction—features that are ≥99.9% linearly separable in Qwen2.5-1.5B's activation space
- **Nonlinear features show degraded introspection**: Sub-category classification accuracy drops to 97.5%, and borderline self-prediction drops to 90%
- **Confidence tracks task difficulty**: The model reports significantly lower confidence on ambiguous cases (0.81 vs 1.00, p = 0.021), demonstrating meta-cognitive awareness
- **Graded harm assessment is well-calibrated**: Spearman ρ = 0.92 between model harm ratings and reference scores
- **Overall**: Partial support for the linear≈conscious / nonlinear≈unconscious analogy, with a 5 percentage point gap between linear and nonlinear feature introspection (p = 0.064)

